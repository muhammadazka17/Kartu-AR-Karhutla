# 🃏 Kartu AR Karhutla

- **`Kartu_AR_Karhutla_A4.pdf`**: cetak di kertas A4 dengan skala **100%**, lalu potong mengikuti garis. Ukuran tiap kartu **63 × 84 mm**.
- `kartu_1xx_*.png`: file per kartu (1494 × 2000 px).

Setiap kartu memiliki **marker AR unik** (kotak pola hitam-putih bernomor) dan panel pola emas di kiri-kanannya. Keduanya membantu kamera mengenali kartu. Kualitas target sudah diuji (skor 85–100 dari 100).

> ⚠️ Kartu versi awal yang memakai QR code **tidak bisa dipakai**, karena QR-nya sama di semua kartu.
